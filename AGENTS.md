# AEGIS

Local research demonstrator. Python/FastAPI + SQLite in backend/, React/TypeScript in frontend/. Never add external AI calls, runtime CDNs or remote fonts. The only approved hosted dependency is the Supabase development project AEGIS-Development for the longitudinal record (backend/aegis/medical, supabase/migrations); it holds synthetic data only, every table keeps RLS, and the app must keep working offline with AEGIS_RECORD_BACKEND=memory (default). Schema changes go through versioned migrations in supabase/migrations; clinical catalogue rows are generated from data/*.json by scripts/build_supabase_seed.py.

Biomarker definitions live in data/biomarker_registry.json and are read at request time. No metric-specific frontend branches. Keep analysis, persistence, guidance and model adapters independent. All measurement dates must have an explicit timezone; store UTC. Reject non-finite values and incompatible units. Preserve source, quality and synthetic provenance. Never pool people or synthetic and real observations. Baselines are separately recorded, never inferred from the same evaluation window.

Missing, expired, invalid-quality or inadequately sampled data cannot produce a normal evaluation. Statistical review flags are research heuristics, never clinical thresholds. No disease probabilities from unvalidated models. Medical guidance requires a reviewed local protocol with reviewer and reference; otherwise show 'Pendiente de revisión médica'. Declared emergency symptoms bypass model inference.

Use pytest for statistical, import, persistence and adapter behavior; Vitest for frontend logic; Playwright for browser flows. Run build and affected tests after changes. Document actual limitations in IMPLEMENTATION_STATUS.md. Make commits for functional phases. Do not commit datasets containing personal information or runtime SQLite files.

The current frontend is AnatomyApp.tsx and AnatomyViewer.tsx: a warm, clear studio interface matching references/. The canonical mesh is assets/models/humanoid.glb; Vite copies runtime meshes into public/models on startup/build. Preserve the real 3D atlas in the overview, without primitive anatomy or remote assets. The user explicitly requested local anatomical images or slow loop videos in system sections: a section with media opens it directly over the hidden (still mounted) 3D atlas; sections without media fall back to a 3D camera zoom (media configured in sectionMedia.ts). The theme is dark (space backdrop with Earth at night in public/media/backdrop.webp). Generated media are authored offline (frontend/scripts/generate-section-video.mjs reads the Sunra key from the git-ignored .env), shipped as local files, labelled as generated and never called at runtime. Preserve verified mesh provenance, exclusions of upstream licence exceptions, and CC BY-SA attribution in assets/models/ATTRIBUTION.md. Keep frame rendering on demand, independent tissue/layer controls in overview, and reduced-motion support. Browser tests use installed Chrome with native Windows D3D11 to exercise the real GLB; they must still block external network in the offline test.
