# Modelo visual

No hay Blender MCP conectado; no se ha generado un GLB ni un archivo .blend.

La aplicación incluye un SVG interactivo y una representación 3D procedural ligera. No hay activos de anatomía de terceros ni licencias pendientes.

Al crear un modelo en Blender, conservar objetos estables region_heart, region_lungs, region_kidneys, region_muscles, region_skeleton, region_brain y region_metabolic. Guardar humanoid.blend y exportar humanoid.glb en esta carpeta. Mantener separada la geometría por sistemas, documentar licencia y unidades y evitar texturas externas. Ver docs/ARCHITECTURE.md para conectarlo al frontend y preservar la alternativa accesible.
