# NASA Explorer

Landing page inspirada en la exploración espacial y la ciencia de la NASA.

## Características

- Diseño moderno y responsivo
- Tema espacial con colores inspirados en el cosmos
- Sección de misiones y descubrimientos
- Estructura simple para seguir desarrollando el proyecto

## Estructura del proyecto

- `index.html` — estructura principal de la página
- `style.css` — estilos visuales y diseño responsivo
- `script.js` — scripts complementarios

## Cómo ejecutar

1. Abre `index.html` directamente en el navegador, o
2. Sirve la carpeta localmente con un servidor estático.

Ejemplo con Python:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000`.
